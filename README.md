# Bouncing Ball Game

A classic Bouncing Ball brick-breaker game built with pure HTML, CSS, and Vanilla JavaScript, utilizing the HTML5 Canvas API.

## Features

- **Classic Gameplay**: Bounce the ball off the paddle and walls to break all randomly placed bricks.
- **Responsive Paddle Control**: Move the paddle smoothly using your mouse or pointer across the canvas.
- **Collision Physics**: Accurate circle-rectangle collision detection for bricks and the paddle, preventing ball clipping and double-bounce tunneling.
- **Win Detection**: Automatically ends the game and notifies you once all bricks are cleared.

## Technologies

- HTML5 Canvas
- CSS3
- Vanilla JavaScript (ES Modules)
- ESLint, Prettier, Husky, and `lint-staged`
